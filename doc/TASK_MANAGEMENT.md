# موديول إدارة المهام والمشاريع

دليل مختصر للي اتبنى، وإزاي يشتغل، وإيه المطلوب على السيرفر.

---

## 1. المطلوب على السيرفر

### الجدولة (إجباري للأتمتة)
الكرون الموجود بيكفي — الأمر الجديد متسجّل في `routes/console.php`:

```
* * * * * cd /path-to-project && php artisan schedule:run >> /dev/null 2>&1
```

`tasks:automation` بيشتغل كل 5 دقايق ويعمل:
1. المهام المتكررة اللي ميعادها جه
2. تذكير قرب موعد التسليم
3. تنبيه المهام المتأخرة
4. تذكير تحديث نسبة الإنجاز
5. قفل العدادات المنسية

آمن لو اتشغّل أكتر من مرة (مابيكرّرش حاجة).

### التحديث اللحظي (اختياري)
في `.env`:
```
BROADCAST_CONNECTION=pusher
PUSHER_APP_ID=...
PUSHER_APP_KEY=...
PUSHER_APP_SECRET=...
PUSHER_APP_CLUSTER=...
```
من غيره كل حاجة شغالة، بس من غير التحديث الفوري (الإشعارات بتظهر لما الجرس يتفتح).

### إعدادات اختيارية (`config/tasks.php`)
| المتغير | الافتراضي | معناه |
|---|---|---|
| `TASK_ATTACHMENT_MAX_KB` | 10240 | أقصى حجم للملف المرفق |
| `TASK_ATTACHMENTS_DISK` | local | مكان تخزين المرفقات (خاص) |
| `TASK_MAX_TIMER_HOURS` | 12 | العدّاد المنسي بيتحسب بالحد ده |
| `TASK_DUE_SOON_HOURS` | 24 | تذكير قرب التسليم قبل الموعد بكام ساعة |

### بعد الرفع
```
php artisan migrate
```
وبعدها من شاشة الصلاحيات: إدّي الأدوار صلاحيات "المهام" و"المشاريع" المناسبة.

## 2. الصلاحيات (لوحة الإدارة)

| الصلاحية | بتسمح بإيه |
|---|---|
| `task_show` | قائمة المهام والتفاصيل والتقويم |
| `task_create` / `task_update` / `task_delete` | إنشاء / تعديل / حذف |
| `task_assign` | تعديل المكلّفين |
| `task_review` | اعتماد أو إرجاع أي مهمة مسلّمة |
| `task_board` | لوحة المهام المباشرة (كانبان) |
| `task_recurrence_manage` | المهام المتكررة |
| `task_report` | تقارير المهام والأداء |
| `project_*` | المشاريع (عرض، إنشاء، تعديل، حذف، سلة) |
| `project_template_manage` | قوالب المشاريع |

مشرف الفرع بيشوف فرعه بس في كل الشاشات (عزل تلقائي).

## 3. الموظف في البوابة (بدوره في المهمة، مش بصلاحيات)

| الدور | يقدر |
|---|---|
| اللي عمل المهمة / مدير المشروع | يعدّل، يكلّف، يربط، يعتمد، يلغي، يحذف |
| المكلّف | يبدأ، يحدّث النسبة، الخطوات، الوقت، يسلّم للمراجعة، يعتذر |
| المدير المباشر للمكلّف | يتابع ويعتمد أو يرجّع |
| عضو المشروع | يشوف ويضيف مهام · المشاهد يشوف بس |

**المراجع** وقت التسليم: اللي عمل المهمة — ولو الموظف عملها لنفسه: مديره المباشر — ولو مالوش مدير: يقفلها مباشرة.

## 4. هيكل الكود

| المكان | المسؤولية |
|---|---|
| `app/Services/Tasks/TaskAccess` | مين يقدر يعمل إيه (مصدر واحد للقواعد) |
| `app/Services/Tasks/TaskService` | الإنشاء، الحالة والمراجعة، النسبة، التكليف، الخطوات، الارتباط |
| `TaskCollaborationService` | التعليقات والإشارة والمرفقات |
| `TaskTimeService` | العدّاد والوقت اليدوي |
| `TaskBoardService` | كانبان والتقويم |
| `TaskMetricsService` | مقاييس التقارير |
| `TaskRecurrenceService` / `TaskReminderService` | الأتمتة |
| `TaskNotifier` / `TaskBoardBroadcaster` | الإشعارات والبث اللحظي (بيسمعوا أحداث `app/Events/Tasks`) |
| `app/Services/Projects/*` | المشاريع والأعضاء والقوالب |
| `resources/views/tasks/partials` | شاشات مشتركة بين اللوحة والبوابة |

### قنوات البث
- `private-employee.{id}` — إشعارات الموظف
- `private-tasks-board.{branchId}` و `private-tasks-board.all` — لوحة المهام المباشرة

### الأداء
- العدادات (المهام الفرعية، الخطوات، التعليقات، المرفقات، الوقت، نسبة المشروع) مخزّنة على الصف وبتتحدّث مع كل تغيير — القوائم واللوحة مابتعملش استعلام لكل كارت.
- اختبار `NPlusOneCrawlTest` بيمر على كل الشاشات ببيانات متعددة وبيفشل لو ظهر N+1.

## 6. بيانات تجربة (محلي بس)

```
php artisan tasks:demo           # إنشاء
php artisan tasks:demo --fresh   # مسح القديم وإنشاء من جديد
php artisan tasks:demo --clean   # مسح بيانات التجربة بس
```

بيعمل 4 موظفين تجربة بدخول البوابة (كلمة المرور `password`، الهواتف `01099900001` لـ `01099900004`)
ومهام في كل الحالات والسيناريوهات ومشروعين وقالب ومتكررة وإشعارات.
تفاصيل كل حساب وهتلاقي فيه إيه: أول ملف `app/Console/Commands/TaskDemoCommand.php`.
الأمر بيرفض يشتغل لو `APP_ENV` مش `local`.
