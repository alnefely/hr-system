# مهارة التصميم والالتزام بالقوالب الجاهزة

## الوصف
هذه المهارة تُجبر الوكيل على استخدام التصميمات والمكونات الجاهزة الموجودة داخل المشروع فقط، وتمنعه من اختراع أو كتابة أكواد CSS أو HTML إضافية من الصفر.

## التعليمات والقواعد الصارمة
1. **فحص مجلد Vuexy أولاً**: 
   - عند طلب أي تصميم لوحة تحكم، يجب عليك أولاً الانتقال إلى المجلد `/vuexy` وفحص ملفات التصميم والـ HTML/CSS المتاحة فيه.
   - استخدم الهيكل العام والتنسيقات (Layouts & Themes) الموجودة داخل `/vuexy` فقط.

2. **فحص مجلد المكونات الجاهزة (Blade Components)**:
   - قبل بناء أي عنصر (أزرار، جداول، بطاقات، نماذج إدخال)، يجب عليك فحص المجلد `resources/views/components/`.
   - استدعِ المكونات الجاهزة من هذا المسار مباشرة واستخدمها.

3. **حظر الأكواد الإضافية**:
   - يُمنع منعاً باتاً كتابة كود CSS مخصص جديد (Custom CSS).
   - يُمنع تكرار بناء عناصر لها بديل جاهز في المكونات.
   - إذا لم تجد المكون المطلوب، اطلب إذن المطور أولاً أو استخدم أقرب مكون متاح لأسلوب التصميم الحالي.

4. **طريقة الاستدعاء**:
   - اعتمد على مسارات الملفات الصحيحة للاستيراد (Import) أو استدعاء مكونات Blade عبر الرمز `@component` أو `<x-component-name />` بناءً على الهيكل المعتمد في المشروع.
